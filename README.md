# C-Pointer-Logic-Math
A specialized C repository demonstrating modular system design through function pointer arrays. Includes implementations for geometric property solvers and arithmetic dispatch tables, focusing on efficient memory and logic flow.

C-Pointer-Logic-Math
A demonstration of modular programming in C using function pointers to handle complex mathematical logic and geometric calculations.

📂 Included Files
geometric_pointer_logic.c: Calculates circle/sphere properties using a function pointer dispatch table.

modular_math_system.c: A modular calculator that maps user input to arithmetic functions via pointers.

🚀 How to Run
VS Code

Compile and run:

gcc filename.c -o output
./output
